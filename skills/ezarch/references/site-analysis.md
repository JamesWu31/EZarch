# 场地、环境与技术分析

按任务选择区域、邻里、基地、建筑、房间或节点尺度。每图回答“问题 → 数据/假设 → 方法 → 结果 → 设计响应”，不用相同底图换色凑数量。

用户测绘/规划资料优先。公开道路/建筑可查 OpenStreetMap：https://www.openstreetmap.org/copyright 、https://wiki.openstreetmap.org/wiki/Overpass_API 。遵守服务规则，查询有界范围，保存响应和署名。地形、气象、规划条件分别记来源、日期、坐标系和可靠性，截图不自动成为精确地形。

明确地理北、项目北、坐标投影和标高；经纬度不能直接当米算距离。假想基地必须在图面标“设计假定”，不能写成真实调查。

区位说明位置和到达；交通说明道路、人车服务路径与冲突；功能说明活动和邻接；技术说明结构路径、围护层次、连接和排水意图。色块不是交通调查，结构示意不是验算。

`ezarch.analysis.solar_position()`、`shadow_vector()` 支持基础太阳/水平地面影长：输入经纬度、带时区时间和高度。NOAA 近似算法不含复杂地形、反射、大气折射或法定日照时数求解；体量遮阴要投影实际几何。采光、能耗、风环境的定量结论需专门求解器与边界条件，没有计算只交明确标注的策略图。

地图检查比例、北向、图例、出处和范围；数值图检查单位、工况、方法及色阶含义；路线不穿不可通行构件；解释结果怎样改变设计。模型修改后更新关联分析。
