# 规范适用与依据查询

规范是设计约束的一部分，制图符号、设计经验和审美偏好属于不同层面。查询围绕当前问题展开，不要求每次检索全部专业或提交统一合规表。

## 把条文用于具体判断

先从资料识别项目所在地、用途、规模/高度、设计阶段及相关的现状/新建条件。查询主管部门发布公告、正文和适用地方规定，核对生效时间、修改/废止内容及适用范围，再定位影响当前设计的条款。只有搜索摘要、标准名称或二手图解不足以支持具体数值。

对要采用的尺寸或指标，弄清测量定义：净宽还是轴线间距、结构面还是完成面、建筑面积还是使用面积、绝对标高还是相对标高。落实到对应几何、路线、构件或表达，再核对结果。条文有触发条件、例外或不同建筑类型时保留这些条件；不把某个项目的数值写成所有项目的默认值。

正文、条文说明、推荐做法和自己的设计推断分别表述。地方规划条件、用地红线、退界和容积率来自本项目适用资料，不能从通用住宅规则推定。概念阶段可有不同表达深度，但已经适用的约束不会因图面简化而消失。

## 检索入口（按问题选用）

以下是检索起点，不是最新规范全集。实施时仍应核对有效版本与当地要求；最后整理日期 2026-10-15。

| 问题 | 可查依据及入口 |
|---|---|
| 民用建筑空间、部位及使用安全 | GB 55031—2022《民用建筑通用规范》；[出版方正文入口](https://ebook.chinabuilding.com.cn/zbooklib/bookpdf/probation?SiteID=1&bookID=154710) |
| 住宅项目 | GB 55038—2025《住宅项目规范》；[住建部公告](https://www.mohurd.gov.cn/gongkai/zc/wjk/art/2025/art_66adac27fa2144bb86f98fe4c297efd6.html)、[政府公开正文](https://ghzrzyw.beijing.gov.cn/biaozhunguanli/bzzl/202506/P020250609570099619169.pdf) |
| 防火、疏散与救援条件 | GB 55037—2022《建筑防火通用规范》；[住建部发布入口](https://www.mohurd.gov.cn/gongkai/zhengce/zhengcefilelib/202301/20230118_770016.html)；结合建筑类型和有关标准有效条款 |
| 无障碍连续通行与设施 | GB 55019—2021《建筑与市政工程无障碍通用规范》；[政府发布入口](https://www.beijing.gov.cn/zhengce/zhengcefagui/qtwj/202204/t20220412_2674451.html) |
| 图纸表达 | GB/T 50001、GB/T 50104、总图制图标准及项目制图要求；见 [制图参考](chinese-drafting.md) |
| 规划、气候、日照、采光、节能、声学或特定建筑类型 | 根据项目问题检索国家与地方主管部门、标准发布机构及对应技术资料；没有一套统一阈值适用于全部场景 |

住宅新规自 2025-05-01 实施，公告废止 GB 50368—2005 和列明标准的部分强制性条文；不能据此把 GB 50096 等整本标准说成全部废止。引用时查看正文与公告对应关系。

可保留项目自己的轻量笔记：来源、版本、适用条件、相关条文、几何测量及尚未核实事项。形式自由，不要求用户填写。缺少地点、用途等真正改变结论的条件且资料中找不到时再澄清；不能凭默认城市或默认建筑类型宣布合规。

未完成结构、消防等相应专项验证时，只说明已核验的范围。图纸看起来规范、DXF audit 成功、符号符合制图规则，均不等于整项设计已经满足全部技术要求。
