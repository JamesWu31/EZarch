# 中国建筑制图表达

适用规则由任务、地区、建筑类型和设计阶段确定。制图符合某些条文不等于建筑技术、结构、消防或施工合规。本库为表达助手，不是规范认证软件。

## 核查依据与范围

基础来源：GB/T 50001—2017《房屋建筑制图统一标准》（第1695号公告，2018-05-01实施），GB/T 50104—2010《建筑制图标准》（第747号公告，2011-03-01实施）；总平另核查《总图制图标准》。执行新项目时核实适用版本和项目要求。发布/目录入口：https://www.gongbiaoku.com/mobile/book/nzg18501zaz （出版方工标库）；GB/T 50001—2017核查文本：https://download.hustp.com/d/file/word/2023/01/20230104_212222.pdf （公开镜像，需与正式标准核对）。不在仓库分发整本标准。

以下是已用于助手的局部表达规则和条文定位，不是全文合规清单：

| 表达 | 依据 | 实施/检查 |
|---|---|---|
| 文字/线条不混淆 | 50001 §4.0.10、§5 | 按实际纸面检查碰撞，按字体类型选字高；字母数字不小于2.5mm |
| 比例 | §6 | 模型1:1，纸面定比例，不缩放后保留旧比例标签 |
| 常用剖切符号 | §7.1.4 | 粗位置线6–10mm、垂直方向线4–6mm；检查方向、编号、图纸对应 |
| 索引 | §7.2 | 圆及分隔线，上编号/下图号；助手为普通跨图纸形式，特殊形式自行适配 |
| 引出线 | §7.3 | 说明与对应构件关联，避免交叉，多层做法按构造顺序 |
| 指北针 | §7.4.3 | 普通圆直径24mm、尾宽3mm；与项目北向一致 |
| 定位轴线 | §8 | 点划线、圆径8–10mm；通常横数字纵大写字母，I/O/Z不用 |
| 尺寸 | §11.1–11.3 | 真值、细尺寸线、斜短线；界线离轮廓≥2mm，超线2–3mm；分尺寸靠近图形、总尺寸置于外侧，间距按图面组织 |
| 标高 | §11.8 | 三角尖端对应高度；m、三位小数；零为±0.000，正值不写＋ |

参数见 assets/drafting/china-conventions.yml，Drawing使用的 pen 可按项目覆写。统一风格不是只换仿宋；附带字体为开放仿宋风格 TTF，不冒称微软字体或工程SHX。

## 随图纸选择完整度

平面：轴网与定位、房间/功能、必要面积、门窗编号、开门/楼梯方向、尺寸组织、标高、剖切和节点索引、图名图号比例。立面：轴线端点或定位、主要标高、洞口及构件尺寸、材料分区/编号、必要节点索引。剖面：对应剖切、楼地面/屋面/基础的项目所需层次、净高层高、楼梯和空间关系、标高、尺寸、做法与节点引用。详图：比例适合内容，层次与连接清楚，尺寸和材料说明闭合。未设计的层次不能用随机线条补画。

一套成果中的轴线、门窗号、材料号、图号、标高基准必须互相对应。图面空间不足先调整组织、比例或分图，不把字缩到不可读。总图标坐标/北向/尺度/现状与设计范围；分析图的箭头和颜色不是工程规范符号。

## 二维图块

Drawing.furniture 提供普通可编辑 chair/sofa/bed/table/counter/cabinet/shelf/sink/wc/shower/equipment 线条，按真实外廓和旋转生成；这些是表现惯例，不称国家标准家具。特殊家具按参考生成。视图比例控制简化程度，实际使用空间另行校核。

## 使用

`ezarch.drafting.Drawing(bounds, scale, title, number)` 独立于三维。bounds 包含注释区（世界mm）；poly/text/axis/dimension/chain/level/north/section_mark/index/leader/furniture 生成同源 DXF/PDF/SVG。pen与文字高度为纸面mm，物体坐标为模型mm。

模型视图可设置 drafting 命令列表，op为以上方法名，其余键为方法参数；drawing_bounds显式预留标注区。所有标注由项目按任务组织，不自动把相同符号撒到每张图。
